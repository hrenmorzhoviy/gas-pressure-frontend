# Газовый каталог — лабораторная работа 5

Учебное SPA для просмотра карточек газов. Стек — React, TypeScript, React-Bootstrap и Vite. Данные берутся из локальной коллекции `src/modules/mock.ts`. В нижнем меню доступны «Лента» и «Газы». «Добавить» и «Вход» отключены согласно заданию ЛР5, их демонстрационные страницы открываются по прямым адресам.

## Запуск

Требуется Node.js 22.12 или новее.

```bash
npm ci
npm run dev
```

По умолчанию Vite открывает `http://localhost:3000`. Для проверки исходников используйте `npm run lint`, для сборки — `npm run build`. Сервер и учётная запись не нужны.

## Страницы

### Газы — `/gases` и `/`

На плитке показаны изображение, название, молярная масса в г/моль, плотность в кг/м³ и число лайков. Два ползунка задают нижнюю и верхнюю границы молярной массы. Нажатие на «Применить фильтр» обновляет список. Нажатие на карточку открывает соответствующий газ в ленте.

### Лента — `/feed` и `/feed/:id`

Страница показывает один газ. Видео воспроизводится без звука в цикле. «Ещё» раскрывает описание, «Скрыть» сворачивает его. Блок «Характеристики» показывает пары «название – значение», когда они заданы для газа. Отображаются масса, плотность и счётчик лайков. Кнопка лайка недоступна гостю. «Следующий» открывает следующую карточку, после последней снова показывается первая.

### Добавление — `/add`

Демонстрационная форма из двух шагов. Сначала вводится название газа и при желании выбираются изображение и видео с предпросмотром. «Далее» открывает поля описания, молярной массы и плотности. «Назад к названию и файлам» возвращает к первому шагу с введёнными значениями. «Опубликовать» проверяет поля, сбрасывает форму и подтверждает завершение демонстрации. Данные не записываются в каталог.

### Вход — `/login`

Макет страницы содержит поля «Имя пользователя» и «Пароль» и кнопку «Войти». Элементы отключены. Работающая аутентификация относится к ЛР6.

## Реализация

- `MassFilter` получает диапазон, допустимые границы и обработчики через props. `CatalogPage` хранит вводимый и применённый диапазоны в `useState`.
- `ReelsPage` выбирает карточку по `useParams` и переключает карточки через `useNavigate`.
- `AddPage` хранит поля и шаг формы в `useState`. Через `useEffect` освобождаются временные URL предпросмотра файлов.
- Изображения и видео подставляются из `public`, если медиа у карточки нет или оно недоступно. В ЛР5 данные не запрашиваются через API.
